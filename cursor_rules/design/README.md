# Design System - LA DALLE

Ce dossier contient toutes les règles de design et UI/UX pour le projet LA DALLE.

## Structure

- **typographie/** : Système typographique (polices, tailles, hiérarchie)
- **couleurs/** : Palette de couleurs et thème
- **icones/** : Système d'icônes et bibliothèque utilisée
- **spacing/** : Grille, espacements, système de padding/margin
- **shadows/** : Bordures et ombres brutalistes
- **composants/** : Guidelines pour chaque type de composant UI

## Principes généraux

- Design mobile-first
- Focus Gen Z : animations, micro-interactions, design moderne
- Growth Hacking : gamification, partage social, engagement
- Accessibilité : respect du RGAA et WCAG 2.1 AA minimum
