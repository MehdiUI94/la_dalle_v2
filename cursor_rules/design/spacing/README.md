# Spacing

## Système d'espacement

Utiliser Tailwind CSS pour tous les espacements.

## Grille

- Base : 4px (0.25rem)
- Multiples recommandés : 4, 8, 12, 16, 24, 32, 40, 48, 64px

## Padding/Margin

- Utiliser les classes Tailwind : `p-4`, `m-8`, etc.
- Éviter les valeurs arbitraires sauf cas exceptionnel

## Scrollbar

- Espace à droite : 8px
- Espace en haut/bas : 40px
