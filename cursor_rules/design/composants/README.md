# Composants UI

Ce dossier contient les guidelines pour chaque type de composant.

## Types de composants

- **forms/** : Formulaires, inputs, selects, checkboxes
- **navigation/** : Header, footer, menus, breadcrumbs
- **cards** : Cartes de contenu, cartes de deals
- **buttons** : Boutons primaires, secondaires, actions
- **modals** : Modales, dialogs, popups

## Principes communs

- Réutilisabilité
- Accessibilité (RGAA)
- Responsive design
- Animations et micro-interactions (Gen Z)
