# Icônes

## Bibliothèque

- **Lucide Vue Next** : Bibliothèque principale d'icônes

## Usage

- Utiliser des icônes cohérentes dans toute l'application
- Taille standard : 24px (ajuster selon le contexte)
- Couleur : hérite de la couleur du texte par défaut

## Guidelines

- Préférer les icônes simples et reconnaissables
- Maintenir la cohérence visuelle
- Utiliser des icônes accessibles (avec aria-label si nécessaire)
