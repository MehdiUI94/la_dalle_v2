# Accessibilité

Ce dossier contient toute la documentation sur l'accessibilité pour le projet LA DALLE.

## Objectif

**RGAA 4.1 niveau AA minimum** (conformité française)

## Documentation

- **RGAA.md** : Référentiel Général d'Amélioration de l'Accessibilité (version française)
- **WCAG.md** : Web Content Accessibility Guidelines (référence internationale)

## Principes essentiels

- Toutes les images doivent avoir un `alt`
- Tous les formulaires doivent avoir des `<label>`
- Contraste minimum 4.5:1 pour le texte
- Navigation au clavier fonctionnelle
- Focus visible sur tous les éléments interactifs
- Structure HTML5 sémantique
