# Conventions Git

## Messages de commit

Format : `type(scope): description`

### Types

- `feat` : Nouvelle fonctionnalité
- `fix` : Correction de bug
- `docs` : Documentation
- `style` : Formatage, CSS
- `refactor` : Refactoring
- `test` : Tests
- `chore` : Tâches de maintenance

### Exemples

```
feat(auth): ajout de la connexion client
fix(map): correction du positionnement des marqueurs
docs(readme): mise à jour de la documentation
style(header): amélioration du design du header
```

## Branches

- `main` : Branche principale (production)
- `develop` : Branche de développement
- `feature/nom-feature` : Nouvelles fonctionnalités
- `fix/nom-bug` : Corrections de bugs
- `hotfix/nom-urgence` : Corrections urgentes

## Pull Requests

- Description claire des changements
- Référencer les issues liées
- Demander des reviewers si nécessaire
