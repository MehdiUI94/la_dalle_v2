# Conventions

Ce dossier contient toutes les conventions de code, nommage et Git pour le projet.

## Structure

- **nommage/** : Conventions de nommage (fichiers, variables, fonctions)
- **code/** : Standards de code, patterns, bonnes pratiques
- **git/** : Conventions Git (commits, branches, PR)

## Principes généraux

- Cohérence dans tout le projet
- Lisibilité avant tout
- Respect des conventions de la communauté Vue/TypeScript
