# Stack Technique

Ce dossier contient la documentation technique des outils et bibliothèques utilisés dans le projet.

## Outils

- **supabase/** : Base de données, authentification, Realtime
- **leaflet/** : Cartes interactives, marqueurs, popups

> **Note** : La documentation sur l'accessibilité (RGAA, WCAG) se trouve dans `cursor_rules/accessibilite/`

## Vue 3 + TypeScript

- Composition API uniquement
- TypeScript strict
- Vite pour le build

## Autres outils

- Pinia pour la gestion d'état
- Vue Router pour la navigation
- Tailwind CSS pour le styling
