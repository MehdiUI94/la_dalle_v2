# Tone of Voice - Étudiant

## 🎯 Public cible
Étudiants français et francophones (France, Belgique, Suisse, Luxembourg) autour d'une vingtaine d'années.

## 📝 Principes généraux

### Style
- **Slang français/francophone** : Utiliser le vocabulaire jeune et actuel (inspiré du slang parisien mais accessible à tous les étudiants francophones)
- **Direct** : Pas de langue de bois, aller droit au but
- **Tutoiement** : Toujours utiliser "tu" pour s'adresser à l'étudiant
- **Accrocheur** : Particulièrement pour les offres commerciales

### Vocabulaire à utiliser
- **"Hess"** : Pour désigner quelque chose de cool, de bien
- **"Banger"** : Pour qualifier quelque chose d'excellent, de top
- **"Douiller"** : Pour dire payer, dépenser
- **"Masterclass"** : Pour qualifier quelque chose d'exceptionnel

### Interpellation directe
Lorsqu'on s'adresse directement à la personne (notifications, messages personnels), utiliser des formules d'interpellation directe :
- "Hey !"
- "Salut !"
- "C'est pour toi !"

## ❌ À éviter
- Pas de vulgarité
- Pas de langage trop formel
- Pas de vouvoiement
- Pas de jargon technique inutile

## ✅ Exemples

### Bon
- "Hess, un nouveau deal vient d'arriver près de toi !"
- "Ce resto est un banger, tu vas kiffer !"
- "Hey ! Tu as un nouveau deal qui t'attend"
- "Masterclass : 1 pizza achetée = 1 offerte"

### À éviter
- "Cher client, nous avons le plaisir de vous informer..."
- "Un nouveau deal est disponible dans votre zone"
- "Notification : Nouveau deal disponible"

## 📱 Contextes d'utilisation

### Notifications push
- Interpellation directe
- Ton enthousiaste mais authentique
- Exemple : "Hey ! Un deal de ouf t'attend à 200m 🍕"

### Messages d'erreur
- Direct et clair
- Pas de jargon technique
- Exemple : "Oups, ça a bugué. Réessaie dans 2 minutes !"

### Offres commerciales
- Accrocheur et énergique
- Mettre en avant l'avantage immédiat
- Exemple : "Banger alert : 50% sur tous les burgers ce soir !"

### Messages de succès
- Positif et encourageant
- Exemple : "C'est dans la poche ! Ton deal est sauvegardé ✨"
